# Colors

A civic palette: deep municipal greens, one gold thread from the city seal, and paper white for records. Each swatch reads the live token in both themes, so this page always matches `tokens/tanaw.css`. Use the **role tokens** (`--tanaw-*`) in components: they change with the theme. The static brand colours (`--color-tanaw-*`, Tailwind utilities like `bg-tanaw-civic`) never change.

## Rules

- **The One Action Green Rule.** Only Civic Green fills an action. Other greens are text, outlines or atmosphere.
- **The Gold Thread Rule.** Gold appears as lines and marks, never as fills or body text.
- **The Seal Rule.** Navy (`--color-tanaw-navy`) belongs to the city seal and map artwork. Page titles are Ink.
- **No new greens.** Map any green to Civic Green, Ledger Green, Forest Label or Canopy.
- Category tones (teal, purple and the status colours) name a kind of thing in metric strips and badges. They are not decoration.
