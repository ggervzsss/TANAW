# Typography

**Bai Jamjuree** (`font-display`) gives the wordmark, page titles and section headings an official, engineered voice. **Inter** (`font-sans`, the default) carries every figure, label, sentence, table and form. Montserrat is retired.

## Rules

- **The Ledger Number Rule.** Every count uses tabular figures (`tabular-nums`). In tables, numbers are right-aligned so digits line up.
- **The Named Figure Rule.** Every number has a label saying what it counts and, where it matters, when.
- **Case.** Uppercase with tracking is only for labels that name a figure, a column or a section. Buttons, badges, filters and headings are sentence case.
