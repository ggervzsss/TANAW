# Adding or changing a component

1. **Write it in `design-system/src/components/` (a primitive) or `src/patterns/` (a composite).**
   - React + TypeScript + Tailwind, working on React 18 (desktop) and React 19 (web): use `forwardRef` for refs, no ref-as-prop and no `use()`.
   - Type-only imports (`import type`), no enums or namespaces (both apps use `verbatimModuleSyntax` and `erasableSyntaxOnly`).
   - Relative imports only (`../lib/cn`), never an app alias such as `@/`.
   - Colours from role tokens; no new hex values. Document each prop with a `/** comment */`; it appears in the Docs tab.
2. **Export it from `src/index.ts`.**
3. **Add stories** next to it (`Name.stories.tsx`) covering every state: default, hover, focus, active, disabled, loading, error, and dark mode through the toolbar.
4. **Sync and check both apps:**

```bash
node design-system/scripts/sync.mjs
cd desktop-tanaw && npm run type && npm run lint && npm test
cd ../frontend-tanaw && npm run type && npm run lint && npm test
```

5. **Commit the source and both copies together.** `node design-system/scripts/sync.mjs --check` reports drift without writing.

## Changing tokens

Edit `design-system/tokens/tanaw.css` and the matching value in `DESIGN.md`'s frontmatter, then run the same sync.
